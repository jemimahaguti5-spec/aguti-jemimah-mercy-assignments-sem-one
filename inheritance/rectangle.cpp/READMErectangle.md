# Rectangle Class in C++

## Description
This program demonstrates the use of classes and objects in C++.
It defines a class called `Rectangle` that stores the length and width
of a rectangle and calculates its area.

## Objectives
- To understand how to declare a class in C++.
- To understand private and public access specifiers.
- To learn how to use member functions to set and retrieve data.
- To create objects from a class.
- To calculate the area of a rectangle.

## Program Features
- Stores the length and width as private data members.
- Uses setter functions to assign values.
- Uses getter functions to retrieve values.
- Calculates the area using the formula:

  Area = Length × Width

## Technologies Used
- Programming Language: C++
- Code Editor: Visual Studio Code
- Compiler: g++

## How to Compile and Run

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Compile the program using:

   g++ rectangle.cpp -o rectangle

4. Run the program using:

   ./rectangle

   On Windows, use:

   .\rectangle.exe

## Sample Output

Length: 10
Width: 5
Area: 50

## Conclusion
This program demonstrates the basic concepts of object-oriented
programming in C++. It shows how a class can contain private data
members and public member functions to manage data and perform
calculations.
